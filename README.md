# Aurevia Life Sciences

Corporate website for Aurevia Life Sciences.

## Development

```bash
npm install
npm run dev
```

## Contact form

Set the inbox email in `.env.local`:

```
NEXT_PUBLIC_INBOX_EMAIL=mail@aurevialifesciences.org
```

Optional: `NEXT_PUBLIC_WEB3FORMS_KEY` for Web3Forms instead of FormSubmit.

## Deploy

Deploy on Vercel and add the same environment variables in project settings.
